## Introduction

This document gives worked examples of the proposed data elements in use.
It continues the APDS 4.1 Use Case Document: APDS clause C.1 holds the
domain examples and C.2 the additional use cases, so the APX examples are
numbered C.3. Several build directly on APDS examples, in particular
C.2.2 (parking enforcement and user check-in) and C.2.4 (a parking
discount scheme).

Each example describes an operation in plain terms, then explains how
the existing APDS data and the proposed additions together support it.
The examples describe data only. How the data is requested or delivered
between systems is outside their scope.
