APX — APDS Parking eXtensions

An open companion standard to the APDS 4.1 API. APX adds what APDS deliberately leaves out — real-time delivery, operational control, alerting, discovery, and the business domains built on them — without redefining a single APDS entity.

Run it locally

git clone https://github.com/rneubauer/apx.git
cd apx && npm install

npm test             # the full gate: vendor, registries, lint, bundle, examples, scenarios
npm run mock         # Prism mock server on :4010, generated from the spec
npm run docs:build   # rebuild this site into site/

The mock server answers every documented route with schema-valid responses, so a client integration can be written and tested before any real implementation exists. Send any bearer token.

What's in it

  • Data profile — full and change update semantics, tombstones, and cursor-based change feeds on APDS's own routes.
  • Delivery fabric — HMAC-signed webhooks, a normative retry schedule, a delivery ledger, and server-sent events.
  • Control — an audited command plane for gates, pay stations, and devices, with perishable commands and honest confirmation levels.
  • Business domains — accounts and payments, LPR, reservations, permits, tolling, customer-service resolution, violations, validations, credentials, and valet.
  • Conformance classes — named, independently claimable feature sets, each with testable requirements in Annex A.
