# APX planning documents

Plans, proposals, design notes and the record of decisions that brought APX to where it is. Nothing here is
normative: the written standard is in [`docs/standard/`](../standard/README.md) and the OpenAPI source, and lasting
design decisions are in [`docs/decisions/`](../decisions/README.md).

This repository is public, so this folder holds only planning about the open standard. Planning about Umojo's own
products, customers and go-to-market is kept privately.
